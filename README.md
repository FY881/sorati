> **سعراتي برو** تطبيق أندرويد لحساب السعرات بالعربي المصري، فيه مدرّب ذكي ووكلاء ذكيين وصوت حقيقي وأكل مصري بجد.

</div>

> **Sorati Pro** is an Android calorie & nutrition coach built for Egyptian food and the Egyptian dialect. It comes with AI agents, a real voice, and a sister app, **Sorati Admin**, which is the owner's private control center.
> This repository is a **showcase only**: screenshots, short animations and a write-up. No source code lives here.

### 🤖 وكلاء في كل ركن في التطبيق

في **17 جزء** من التطبيق فيه وكيل ذكي: الرئيسية، التسجيل، المدرّب، التغذية، المية والصيام، الرياضة، الجسم، النوم، التقارير، المجتمع، اللعبة، العيلة، العضويات، وغيرهم.

- 🧭 **بيتعرّف عليك**: بيبني نموذج شخصي من متوسطات 12 أسبوع، ولو تجاهلت نفس النصيحة 3 مرات بيسكت عنها أسبوع.
- 🔎 **بيدوّر لك**: في مصادر مجانية ومفتوحة للأكل والطقس ومواقيت الصلاة والأماكن.
- ✋ **بيجهّز وانت اللي بتأكد**: رسالة واتساب جاهزة، ميعاد في التقويم، تذكير، طريق على الخريطة، بحث في تطبيق البقالة. **ومفيش حاجة بتتبعت أو تتشري أو تتصل من غير موافقتك.**
- ⚖️ **عادل**: المجاني بياخد تجربة، وكل باقة ليها نصيب على قدّها.

</div>

### 🤖 Agents woven into every part

An agent lives in **17 parts** of the app, from Home, logging and the coach to fasting, sleep, community, family and memberships.

- 🧭 **Learns you.** It keeps a 12-week personal model, and a nudge you ignore three times stays quiet for a week.
- 🔎 **Searches for you.** It uses free, open sources for food data, weather, prayer times and places.
- ✋ **Prepares, you confirm.** It can draft a WhatsApp message, add a calendar entry, set a reminder, plan a route or search a grocery app. **No agent sends, buys or calls anything by itself.**
- ⚖️ **Fair.** Free users get a taste, and every tier gets a share that matches what it costs.

### 🎙️ صوت كأنه استوديو

- 🔧 **صلّحنا الصوت العربي للكل**: مفيش صوت ساكت ولا لكنة غريبة على أي نسخة.

- 🔊 **يقرالك كل حاجة**: زرار عائم، ضغطة طويلة تقرا أي نص، وكمان بيقرا ردود المدرّب والوكلاء والمحادثات أول ما توصل.

- 💸 **مجاني**: بيشتغل على الخطة المجانية بس، وعليه حدود يومية وكاش، ولو الحد خلص يرجع لصوت الموبايل تلقائي.

### 🎙️ A studio-like voice

- 🔧 **Arabic speech fixed for everyone.** No more silent or wrong-accent voice, on any build.
- 💎 **A real AI voice for members.** Pick a female or male voice from previews, then choose the style and speed.
- 🔊 **Reads everything.** A floating button and long-press reading, and new coach, agent and chat replies are read aloud as they arrive.
- 🌅 **A spoken greeting every day** and a **spoken agent brief**.
- 💸 **Costs nothing.** It runs on the free tier only, with daily caps and a cache, and falls back to the phone's own voice automatically.

<div dir="rtl">

مبني بفكرة **«مجاني أولاً»**: كل طلب ليه ميزانية وكاش، ولو الذكاء الاصطناعي مش متاح فيه بديل يشتغل من غيره. والتطبيق بيكمّل شغل حتى من غير نت.

</div>

Built **free-first**: every request is budgeted and cached and has a no-AI fallback, and the app keeps working offline.

| | Layer | What it does |
|:-:|---|---|
| ⚡ | **Edge API: Cloudflare Workers** | One small backend at the edge for AI, sync, community, the game and remote config |
| 🧠 | **Durable Objects + SQLite** | Realtime hub for chat, leagues, agents, feature flags and audit logs |
| ✨ | **Google Gemini (free tier)** | Food photo & text understanding, the coach and the voice, behind a model fallback chain, daily caps and caching |
| 🔐 | **Firebase Authentication** | Google sign-in, with the user's own data synced per account |
| 🌍 | **Open data** | Open Food Facts, Open-Meteo, Aladhan, OpenStreetMap and Wikipedia, all cached |
| 📱 | **Android native shell + web core** | Offline-first UI, native camera, mic, notifications, haptics and widgets, plus adaptive phone, tablet and desktop layouts |

<details>
<summary><b>🛡️ الحماية · Security, in general terms</b></summary>
<br>

- 🔒 **Biometric app lock** for users (opt-in) and **required** on the owner's admin sessions, with a PIN fallback
- 🗝️ **Passkeys** for the owner through Android Credential Manager, plus strong re-auth for sensitive actions
- 🧬 **App integrity**: tamper, repackage, root and hook signals feed a server-side risk score. High risk only holds rewards for review; it never auto-bans
- ✍️ **Signed requests** with replay protection and per-operation rate limits
- 🔐 **Sensitive keys sealed** in the Android Keystore (AES-GCM); **encrypted backups** use AES-256-GCM with PBKDF2
- 🧯 **Kill switches** at every level: global, AI, per version, per feature and per agent
- 🧼 Every user and admin text is length-capped, sanitised and escaped again on display

</details>

<details>
<summary><b>🧪 الجودة · Quality & testing</b></summary>
<br>

- **1,100+ automated server checks** across the harness suites, re-run on every wave
- **Playwright UI suites** for every new screen: Arabic & English × light & dark × phone / tablet / desktop
- **XSS suites** for both apps on every build
- **Live smoke tests** after each deploy, and every server change ships with a **one-command rollback**
- Test accounts are created per run and deleted afterwards

</details>
